# MAS_learn_together
与莫妮卡一起学习新知识

兼容子模式更新插件

添加了学习德语问候语和告别语

添加德语 1-100 数数

在 “学习 ”类别下添加了玩俄罗斯方块的选项！

如何安装

步骤 1 从 github 下载此 MOD

步骤 2 解压缩 Mas_learn_together-#.#.#.zip

! #.#.# 代表版本号

步骤 3 将一起学习文件夹从 Mas_Learn_Together-#.#.#.zip 中移出。

! 不执行第 3 步会导致错误并使俄罗斯方块无法运行。

步骤 4 打开游戏目录

第 5 步 打开 Submods 目录

步骤 6 将 Learn together 文件夹拖放到 Submods 目录中

完成！
